# Jaytech

Personal website for Javier Alva (Jaytech) — Systems Administrator, Developer and AI Specialist.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- Vercel Analytics

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production

```bash
pnpm build
pnpm start
```

The project is designed for deployment on Vercel.
